# FinAI Buddy
FinAI Buddy is a modern, responsive FinTech learning assistant built with Next.js, Tailwind CSS, and shadcn/ui to help users learn personal finance in a smart and interactive way.It offers interactive lessons, quizzes, progress tracking, and an AI-style chat interface in a clean dashboard experience.

## 🚀 Getting Started
```sh
 Clone the Repository
    git clone https://github.com/Kailash987/FinAIance-Buddy.git
    cd FinAI_Buddy


```

## Follow these steps:

```sh
Step 1: Start the Backend Server
    cd backend
    npm install
    npm run dev

Step 2: Start the React Frontend

    💡 Run this in a new terminal
    cd frontend
    npm install
    npm run dev

```


## What technologies are used for this project?

This project is built with:

-Next.js – Full-stack React framework for building performant, SEO-friendly web applications with server-side rendering (SSR) and API routes.

Tailwind CSS – Utility-first CSS framework for fast, responsive, and modern UI design.

Node.js / Express.js – Backend framework for handling server-side logic and RESTful API endpoints.

MongoDB / Mongoose – NoSQL database for storing user profiles, transactions, and financial analytics.

AI/ML Integration (Python / TensorFlow / OpenAI API) – Modules for generating personalized financial insights, budgeting recommendations, and predictive expense analysis.

Next Auth / JWT – Secure authentication and authorization for users.

## 📈 Features
📚 Interactive finance lessons with difficulty levels and progress tracking

📝 Quiz module with instant feedback, progress bar, and final score summary

📊 Client-side progress analytics using interactive charts

💬 Finance learning chat assistant with conversational UI (mock AI responses)

📱 Modern, fully responsive dashboard with persistent sidebar navigation

🔒 Secure authentication and data storage
